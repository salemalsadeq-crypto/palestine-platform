فلسطين بلاتفورم — V65

الهدف: تطوير تجربة «حولك الآن» مع الحفاظ على V64 والبحث الذكي.

التغييرات:
1) الصفحة الرئيسية: قسم «حولك الآن» تفاعلي لا يطلب الموقع إلا عند ضغط المستخدم.
2) بعد السماح بالموقع يعرض أقرب الإعلانات النشطة ومقدمي الخدمات المتاحين.
3) أزرار مباشرة لعرض الإعلان أو مقدمي الخدمة أو الخريطة الكاملة.
4) صفحة nearby.html أصبحت تعرض أيضًا مقدمي الخدمات المتاحين ذوي الإحداثيات.
5) عدادات ونتائج واضحة للمستخدم، مع معالجة هادئة لفشل تحديد الموقع أو الاستعلام.
6) الحفاظ على البحث الذكي V64 وعدم تغيير Supabase أو مفاتيح المشروع.
7) لا يوجد SQL جديد.

اختبارات:
- فحص بناء JavaScript للصفحة الرئيسية وصفحة قريب مني: ناجح.
- فحص جميع السكربتات المضمنة في صفحات المشروع: يجب أن تكون بدون أخطاء نحوية.
