فلسطين بلاتفورم — V82 (واجهة وتنقل موحّدان)

ما تغيّر:
- إضافة ui-polish.css وتفعيله على جميع صفحات HTML الـ54 بعد تنسيقات الصفحات، لتوحيد المسافات والحقول والبطاقات وحالات التركيز والتجاوب.
- تفعيل app-ui.js على جميع الصفحات الـ54، بعد أن كان غائبًا عن 18 صفحة.
- شريط تنقل سفلي للموبايل: الرئيسية، الإعلانات، الريلز، الرسائل، والقائمة الكاملة. لا يضيف زر نشر إعلان ولا زر خروج مكررًا.
- احترام مساحة شاشات الهاتف الآمنة وتقليل الحركة عند تفعيل إعداد تقليل الحركة.
- لم تتغير جداول Supabase أو سياسات RLS أو وظائف قاعدة البيانات، ولا يلزم SQL جديد.

التحقق المنفذ:
- فحص نحوي لملفات JavaScript المحلية باستخدام Node.js.
- التأكد من وجود رابط واحد فقط لكل من ui-polish.css وapp-ui.js في كل صفحة HTML.
- فحص الروابط المحلية؛ النتائج الوحيدة التي ظهرت كانت قوالب صور ديناميكية مثل ${esc(image)}، وليست ملفات ثابتة مفقودة.
- فحص ملفات الواجهة بحثًا عن مفاتيح service_role / sb_secret الواضحة؛ لم يظهر أي تطابق.

حدود التحقق الأمني:
- مفتاح Supabase من نوع publishable/anon الموجود في الواجهة ليس سرًا، لكن أمان البيانات يعتمد على سياسات RLS والتحقق داخل قاعدة البيانات.
- هذه حزمة واجهات؛ لم يتم إجراء اختبار اختراق أو التحقق من صلاحيات قاعدة Supabase الحية من داخل هذه البيئة. لا تُعتبر نتيجة الفحص الثابت شهادة أمن كاملة.

التثبيت:
- استبدل ملفات المشروع بملفات هذه الحزمة في جذر مستودع GitHub نفسه، مع إبقاء أسماء الملفات والمسارات كما هي.
- ارفع التعديلات إلى GitHub Pages وانتظر انتهاء النشر. تم إضافة ?v=82 لتحديث ملفات الواجهة المشتركة وتجاوز النسخ المخزنة مؤقتًا.
