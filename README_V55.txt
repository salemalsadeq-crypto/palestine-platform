# فلسطين بلاتفورم V55 — Performance + RLS Audit

تم تنفيذ V55 على نسخة V54 بعد نجاح SQL V54.

## أهم التغييرات

- تشديد صلاحيات تغيير أدوار المستخدمين ومنع manager من إنشاء/تعديل admin أو manager.
- حماية آخر مدير عام نشط من خفض دوره أو إيقافه.
- تقييد قراءة service_requests لمقدم الخدمة إلى الطلبات المعلقة المطابقة للخدمة والمدينة، مع إبقاء طلباته وطلباته المقبولة متاحة له.
- إلغاء UPDATE المباشر لطلبات الخدمات؛ التحديثات التشغيلية تمر عبر RPCs.
- إلغاء UPDATE المباشر للطلبات التجارية؛ الواجهة تستخدم RPCs.
- إضافة RLS صريح للمحادثات والرسائل.
- منع DELETE المباشر للمحادثات والرسائل؛ حذف المحادثة عبر delete_my_conversation().
- إضافة mark_conversation_messages_read().
- إضافة get_my_conversations() لإرجاع آخر رسالة وعدد غير المقروء بدل تحميل كل الرسائل.
- إضافة get_my_conversation_messages() مع حد أقصى 100/200 رسالة حسب الاستدعاء.
- إضافة فهارس للمحادثات والرسائل والطلبات.
- منع تفعيل مقدم الخدمة مباشرة بدون اشتراك فعال، بما في ذلك عند INSERT.
- جعل تسجيل مقدم الخدمة الجديد يبدأ بحالة غير متاح.
- وضع حد أقصى 5000 حرف للرسالة.
- إضافة حد 100 طلب في صفحة طلبات المستخدم.
