فلسطين بلاتفورم — V87 تجربة الهاتف والتنقل الذكي
=================================================

المصدر: أرشيف V86 الذي زوّدني به المستخدم، مع الإبقاء على ملفات Supabase وسياسات SQL الحالية كما هي.

التحديثات المنفذة:
1) شريط تنقل سفلي متجاوب على الهاتف (الرئيسية، الإعلانات، الريلز، إضافة إعلان، الرسائل، الإشعارات) مع عدادات عند إمكان قراءتها. لا يظهر على تسجيل الدخول/التسجيل أو شاشة الريلز الكاملة.
2) ملف theme-v87.css للتحسينات البصرية، safe-area، حالات التركيز، المسافات، toast، الشريط السفلي وتقليل الحركة.
3) app-ui.js: أداة موحدة ppWithBusyButton، استعادة التمرير عند الرجوع، تحديث شارات التنقل، وتحسين الإشعارات القصيرة.
4) reels.html: تقليل عدد الفيديوهات المحملة، اختيار الفيديو الأوضح ظهورًا لتشغيل واحد فقط، تحميل مسبق للفيديو التالي، وإظهار إجراء لإعادة المحاولة عند خطأ الوسائط.
5) index.html: اقتراحات ديناميكية مبنية على أقسام الإعلانات المحفوظة إن توفرت، مع fallback لأحدث الإعلانات. لا يوجد جدول جديد ولا SQL جديد.
6) messages.html: وضع محادثة مناسب للهاتف، زر رجوع لقائمة المحادثات، رابط ثابت للمحادثة المختارة، ومنع الإرسال المتكرر مع toast.
7) أُضيف تضمين theme-v87.css وapp-ui.js إلى صفحات HTML التي تستخدم platform.js ولا تحتوي تضمينًا سابقًا.

اختبارات محلية: فحص بنية ZIP، وصياغة JavaScript المضمّن في HTML باستخدام Node.js، وصياغة ملفات JavaScript المنفصلة. لم يتم الاتصال بقاعدة Supabase الحية؛ يجب اختبار الصلاحيات والتفاعل على الموقع المنشور.

النشر: احتفظ بنسخة احتياطية؛ ارفع ملفات المشروع كاملة من الأرشيف إلى نفس مكان الموقع، أو ارفع فقط الملفات المعدلة التالية مع theme-v87.css الجديد: app-ui.js, reels.html, index.html, messages.html, وملفات HTML التي أضيف لها تضمين app-ui/theme-v87. لا تشغّل SQL لهذا الإصدار.

ملاحظات: عدادات الرسائل تعتمد على صلاحيات قراءة الرسائل التي يتيحها RLS؛ إن لم تسمح السياسة بالعدّ، يخفي الشريط العداد دون تعطيل المحادثات. التوصيات ليست نظام ذكاء اصطناعي/تنبؤ، بل اقتراحات حتمية حسب فئات الإعلانات المحفوظة ثم أحدث الإعلانات.
