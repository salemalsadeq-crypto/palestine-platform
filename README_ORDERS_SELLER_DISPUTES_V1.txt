تحديث طلبات البائع والاعتراضات — V1
====================================

محتويات التعديل:
- seller-orders.html: صفحة طلبات المبيعات، تعرض طلبات المستخدم بصفته البائع فقط.
- orders.html: يضيف للمشتري زر الاعتراض بعد تسجيل التسليم، ويعرض حالة الاعتراض.
- orders-admin.html: يعرض الاعتراضات ويسمح للمدير/صاحب صلاحية manage_orders بمعالجتها أو رفضها.
- platform.js: يضيف «طلبات المبيعات» إلى القائمة الرئيسية.
- SUPABASE_ORDERS_SELLER_DISPUTES_V1.sql: جدول الاعتراضات ودوال RPC المحمية وتقييد انتقال حالة الطلب.

خطوات التطبيق:
1) احتفظ بنسخة احتياطية من ملفات الموقع الحالية.
2) افتح Supabase Dashboard للمشروع الصحيح ثم SQL Editor.
3) الصق كامل محتوى SUPABASE_ORDERS_SELLER_DISPUTES_V1.sql ونفّذه مرة واحدة. راجع أن النتيجة Success؛ إذا ظهر خطأ، لا تنشر ملفات الواجهة قبل إصلاحه.
4) ارفع الملفات الأربعة (seller-orders.html, orders.html, orders-admin.html, platform.js) إلى نفس مجلد ملفات الموقع مع استبدال النسخ الحالية.
5) ارفع SUPABASE_ORDERS_SELLER_DISPUTES_V1.sql وملف README هذا للاحتفاظ بهما ضمن ملفات المشروع، وليس كصفحات ويب عامة.
6) اختبر بحسابين مختلفين: مشتري وبائع، ثم بحساب إداري لديه manage_orders.

السلوك المقصود:
- البائع لا يرى إلا طلباته، ولا يمكنه تعديل طلب بائع آخر حتى لو استدعى RPC مباشرة.
- انتقالات البائع محدودة؛ تأكيد التسليم متاح بعد التجهيز أو بعد الخروج للتوصيل.
- الضغط على «تأكيد التسليم واستلام المبلغ» هو إقرار من البائع بأن المشتري استلم الطلب وأن البائع استلم المبلغ، وعندها تصبح payment_status = paid.
- لا توجد بوابة دفع مدمجة في هذا التحديث. لا تعتبر حالة online دليلاً على دفع تلقائي؛ المدير يستطيع تأكيدها يدوياً بعد التحقق خارج الموقع.
- المشتري يستطيع فتح اعتراض واحد بعد أن تصبح حالة الطلب delivered. الاعتراض لا يعيد فتح الطلب ولا يسترد المبلغ تلقائياً؛ المدير يراجعه ثم يعالجه أو يرفضه مع ملاحظة اختيارية.
- دور المدير/الموظف يجب أن يمتلك صلاحية manage_orders حتى تظهر إدارة الطلبات والاعتراضات.

ملاحظات:
- تم التحقق من تركيب JavaScript بواسطة node --check للملفات المعدلة. لم يتم تشغيل SQL على قاعدة بياناتك الفعلية من هنا، لذلك يجب التأكد من نجاح تنفيذ ملف SQL في Supabase قبل نشر الواجهة.
- لا يحتوي هذا التحديث على بوابة دفع أو تحويل مالي تلقائي.
