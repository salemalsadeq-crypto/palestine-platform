فلسطين بلاتفورم V25

أهم الإصلاحات:
1. استعادة أقسام الإعلانات: السيارات، العقارات، الوظائف، المتاجر، المطاعم والمقاهي، الخدمات، الإلكترونيات، الأثاث، المواشي، الملابس، بيع وشراء وغيرها.
2. الإبقاء على قائمة الإعلانات والبحث والتصفية أسفل الأقسام.
3. إصلاح البحث القادم من الصفحة الرئيسية عبر ?q=.
4. إصلاح صفحة مقدم الخدمة بالكامل وإضافة حفظ الموقع الجغرافي.
5. إصلاح التاكسي القريب: ترتيب حسب المسافة عند توفر مواقع السائقين، مع بديل تلقائي إذا لم توجد نتائج في مدينة الحساب.
6. إصلاح المراسلة المباشرة مع مقدم الخدمة عبر messages.html?user=.
7. إضافة طلب مباشر للسائق عبر create_direct_service_request.
8. توجيه إشعار الطلب المباشر إلى السائق المحدد فقط.

مطلوب تشغيل SUPABASE_SERVICES_V25.sql مرة واحدة في Supabase بعد تشغيل SQL السابق.
لا تغيّر مفاتيح Supabase الحالية.
