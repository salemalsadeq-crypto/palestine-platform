فلسطين بلاتفورم — V107 (تثبيت بصري أولي)

ما تغيّر:
- إضافة platform-stability-v107.css كطبقة تنسيق مشتركة أخيرة في صفحات HTML الـ61.
- تحسينات بصرية محدودة للتركيز بلوحة المفاتيح، بطاقات المحتوى، التوافق مع الهاتف وتقليل الحركة.
- تحديث Service Worker إلى pp-v107 وإضافة الملفات المشتركة الحالية وملفات السفر إلى قائمة الملفات الأساسية عند توفرها.
- لم تتغير ملفات JavaScript الخاصة بالوظائف أو ملفات SQL أو إعدادات Supabase.

ما لم يتم فعله عمدًا:
- لم تُحذف ملفات CSS القديمة أو ملفات SQL، لأن وجودها قد يكون مقصودًا أو يعتمد عليه إصدار منشور/ترحيل سابق.
- لم يتم الادعاء بأن الحجوزات والطيران مكتملان. المشروع يحتوي صفحات travel-* وملفي travel.js/travel.css، لكن لا يوجد في هذا الأرشيف ملف SUPABASE_TRAVEL_V1.sql الذي تشير إليه رسائل الخطأ في travel.js. يجب استكمال/تحديد مخطط السفر الفعلي قبل اعتبار الحجز مكتملًا؛ لا تشغّل SQL تخمينيًا.
- لم يتم اختبار Supabase الحي أو مسارات المستخدمين في متصفح فعلي.

اختبارات ثابتة أُجريت على هذه الحزمة:
- فحص سلامة ZIP.
- فحص صياغة ملفات JavaScript عبر node --check.
- التحقق من وجود ملفات CSS/JS المحلية المشار إليها (مع استثناء القيم الديناميكية داخل القوالب).
- التحقق من ربط طبقة V107 بجميع صفحات HTML.

خطة الإصدار التالي:
1. اختبار يدوي للصفحات الأساسية: تسجيل الدخول/التسجيل، نشر/تعديل إعلان، الرسائل، التاكسي، الخدمات، الطلبات والاشتراكات.
2. اختبار الحجوزات والسفر بعد تثبيت مخطط قاعدة البيانات المطلوب.
3. بعد إثبات عدم الاستخدام فقط، إعداد قائمة حذف منفصلة للملفات القديمة بدل حذفها تلقائيًا.
