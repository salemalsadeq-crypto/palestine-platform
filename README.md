# فلسطين بلاتفورم — المرحلة الأولى

الميزات الجديدة:
- تحديد موقع الإعلان بإحداثيات GPS عند الإضافة أو التعديل.
- عرض موقع الإعلان على الخريطة في صفحة التفاصيل.
- صفحة `map.html` لخريطة جميع الإعلانات التي لها موقع.
- خريطة خاصة بمواقع المتاجر في `shops.html`.
- نظام تقييمات من 1 إلى 5 نجوم لكل إعلان، مع منع التقييم المكرر ومنع صاحب الإعلان من تقييم إعلانه.

## التثبيت
1. نفّذ `SUPABASE_UPDATE.sql` مرة واحدة في Supabase SQL Editor.
2. ارفع ملفات HTML إلى GitHub Pages مع الحفاظ على الأسماء.
3. اختبر إضافة إعلان وحدد الموقع، ثم افتح تفاصيل الإعلان.
4. لا تحتاج إلى أي مفتاح سري؛ الملفات تستخدم مفتاح Supabase publishable الموجود أصلاً في المشروع.
