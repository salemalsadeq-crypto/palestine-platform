# فلسطين بلاتفورم (Palestine Platform) 🇵🇸

منصة فلسطين الموحدة للإعلانات المبوبة، طلب التاكسي الفوري، الخدمات المهنية، دليل الأماكن والمعالم التراثية، وحجوزات السفر والسياحة.

## المميزات الرئيسية
- **سوق الإعلانات المبوبة**: بيع وشراء السيارات، العقارات، الإلكترونيات، والأثاث مع تصفية حسب المحافظة والمدينة.
- **طلب تاكسي فوري**: حجز سيارات الأجرة وربط فوري بأقرب سائق متاح وتقدير دقيق للأجرة بالشيكل (₪).
- **الخدمات والصيانة**: دليل شامل للمهنيين وفنيي الصيانة وخدمات الشحن والتوصيل.
- **دليل الأماكن القريبة**: استكشاف المطاعم والمحلات التراثية والمعالم على الخريطة مع حساب المسافات.
- **ريلز فلسطين**: استعراض مرئي وفيديوهات قصيرة للمنتجات والمطاعم والأجواء التراثية.
- **طلباتي والشحن**: تتبع دورة حياة الشحنات والطلبات والدفع عند الاستلام (COD).
- **السفر والسياحة**: برامج العمرة والحج، عطلات السفر، وحجوزات الطيران من المكاتب المعتمدة.

## الهيكل التقني
- **تطبيق الأندرويد**: مبني باستخدام **Kotlin** و **Jetpack Compose** مع اتباع معايير **Material Design 3 (M3)** ودعم كامل للغة العربية (RTL).
- **تطبيق الويب التفاعلي**: مبني باستخدام **React 18** و **TypeScript** و **Vite** و **Tailwind CSS**.
