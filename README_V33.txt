# فلسطين بلاتفورم V33
بوابة موحدة لتسجيل مقدمي الخدمات كأفراد أو شركات.
الملفات الجديدة/المعدلة:
- services.html
- provider-register.html
- service-provider.html
- SUPABASE_SERVICES_V33.sql

قبل رفع الملفات:
1. شغّل SUPABASE_SERVICES_V33.sql في Supabase SQL Editor.
2. ارفع الملفات الثلاثة إلى جذر مستودع GitHub واستبدل النسخ القديمة.
3. افتح الخدمات > ابدأ التسجيل كمقدم خدمة.
4. جرّب حسابًا مستقلًا ثم شركة.
