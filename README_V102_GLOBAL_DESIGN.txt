فلسطين بلاتفورم — V102 نظام تصميم موحّد

هذه النسخة مبنية على الملف الذي أرسله المستخدم. التغيير بصري فقط ولا يغيّر JavaScript أو استعلامات Supabase أو قواعد البيانات.

ما الذي تغير؟
- إنشاء ui-system-v102.css كطبقة تصميم مشتركة لكل صفحات HTML الـ55.
- توحيد شكل الأزرار وحقول الإدخال والبطاقات والجداول والتنبيهات وشريط التنقل.
- ضبط المسافات والزوايا والظلال والألوان لتناسب الهاتف والكمبيوتر.
- إزالة روابط CSS محلية تشير إلى ملفات غير موجودة في الأرشيف، مع الإبقاء على ملفات التصميم الموجودة.
- تثبيت صورة القدس النظيفة في خلفية الواجهة الرئيسية ومنع الطبقات الزخرفية القديمة من الظهور داخل بطاقة التاكسي.
- استبدال عبارة «من فلسطين إلى العالم» بعبارة «كل فلسطين في مكان واحد» إذا وجدت في ملفات HTML.
- تحديث Service Worker إلى pp-v102.

طريقة النشر: ارفع محتويات المجلد palestine-platform-main إلى المستودع واستبدل الملفات عند الطلب. بعد النشر، افتح الموقع ثم حدّث الصفحة أو امسح ذاكرة الموقع إن بقيت ملفات قديمة.
